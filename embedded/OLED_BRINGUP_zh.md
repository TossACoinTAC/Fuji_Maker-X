# 0.91 英寸 OLED 首次接线与自检

本文适用于照片中已经焊接接口、丝印为 `GND VCC SCL SDA` 的 `0.91 OLED`。
第一阶段按常见的 SSD1306、128×32、I²C 模块处理，实际地址由专用固件扫描
确认。此阶段不要连接 ST7735S、麦克风、功放、按钮或电池。

## 专用固件

只使用 `fuji-devkit-s3-oled-test`。原来的 `fuji-devkit-s3-display-test` 是
ST7735S SPI 屏固件，不能用于此 OLED。

OLED 专用固件会：

1. 在 GPIO11/GPIO12 上扫描 I²C 地址；
2. 接受常见地址 `0x3C` 或 `0x3D`；
3. 按 SSD1306 128×32 初始化；
4. 依次显示约 700 ms 全亮、约 350 ms 全灭；
5. 最后显示 `OLED OK` 和小智 128×32 状态布局；
6. 未找到 OLED 时继续运行串口诊断，不启动 Wi-Fi、音频或按钮。

## 断电接线

开始前拔掉开发板 `COM` 口 USB 线，并保持电池断开。只接以下四根线：

| OLED 丝印 | ESP32-S3 | 作用 |
|---|---|---|
| `GND` | `GND` | 公共地 |
| `VCC` | `3V3` | OLED 电源，禁止接 `5V` |
| `SCL` | GPIO12 | I²C 时钟 |
| `SDA` | GPIO11 | I²C 数据 |

建议先接 `GND`，再接 `VCC`，最后接 `SCL` 和 `SDA`。所有插拔都必须在
USB 断开时进行。不要根据排针位置猜测，必须逐项核对两端丝印。

## 通电前暂停点

接线完成后仍不要插 USB，确认：

- 四根线与表格完全一致；
- `VCC` 明确连接开发板 `3V3`，没有连接 `5V` 或 `VIN`；
- OLED 接口焊点没有松动，连接器插接牢固；
- ST7735S、麦克风、功放、按钮和电池均未连接；
- 没有裸露导体碰到相邻引脚。

拍摄一张能同时看清 OLED 和开发板两端丝印的俯视近照，先检查接线，再插入
USB 和刷入 OLED 专用固件。

## 观察与报告

正常时应看到全亮、全灭，随后稳定显示 `OLED OK`。串口应报告发现的 I²C
地址和 `SSD1306 128x32 initialized`。

若屏幕无显示、画面偏移、闪烁或开发板复位，立即拔掉 USB。记录屏幕现象和
完整串口日志，不要带电交换 `SCL`、`SDA` 或电源线。若地址扫描成功但画面
异常，模块可能不是 SSD1306，届时再根据现象调整控制器或方向配置。
