# ST7735S 屏幕首次接线与自检

本文只适用于当前照片中的 `1.44-128X128 RGB-TFT`、`ST7735S`、8 针 SPI
屏幕，以及 `fuji-devkit-s3-display-test` 固件。此阶段不要连接麦克风、功放、
按钮或电池。

## 当前暂停点：先解决排针

照片中屏幕 PCB 的 8 个通孔没有焊接排针。普通杜邦线的插针松放在通孔里会
接触不良，也可能让相邻电源和信号短路，因此不能以这种方式通电测试。

接线前必须满足以下任意一种条件：

1. 在屏幕上可靠焊接一条 `2.54 mm 1x8` 直排针；
2. 使用能够独立夹紧每个焊盘且不会相互碰触的测试夹具。

如果套件中有一条 8 针直排针，先把它和屏幕并排拍一张清晰照片，不要自行
通电。若没有排针，购买 `2.54 mm 1x8 单排直针`；没有焊接经验时，可让电子
维修店代焊并检查相邻焊点是否短路。面包板和母对母杜邦线可以用于排针焊好
后的其余连接。

## 断电接线

开始前拔掉开发板 `COM` 口 USB 线，并保持电池断开。按屏幕丝印逐根连接：

| 屏幕丝印 | ESP32-S3 | 作用 |
|---|---|---|
| `GND` | `GND` | 公共地 |
| `VCC` | `3V3` | 屏幕电源，禁止接 `5V` |
| `SCL` | GPIO12 | SPI 时钟，不是 I2C |
| `SDA` | GPIO11 | SPI MOSI，不是 I2C |
| `RES` | GPIO14 | 屏幕复位 |
| `DC` | GPIO13 | 数据/命令选择 |
| `CS` | GPIO10 | SPI 片选 |
| `BLK` | GPIO9 | 背光控制 |

建议先接 `GND`，再接 `VCC`，最后接信号线。`VCC` 只接开发板丝印为 `3V3`
的引脚，不要根据排针位置猜测。所有接线都应在 USB 断开时完成。

## 通电前检查

接好后暂时不要插 USB，逐项确认：

- 屏幕 8 根线与上表一一对应；
- 没有线接到 `5V`、`VIN` 或相邻 GPIO；
- 排针焊点之间没有锡桥、散线或裸金属互碰；
- 杜邦线插接牢固，轻碰线束不会脱落；
- 麦克风、功放、按钮和电池仍未连接。

从正上方拍一张同时看清屏幕端和开发板端丝印的近照，提交检查。确认接线后
再刷入显示专用固件，不能直接刷完整小智固件。

## 自检预期

`fuji-devkit-s3-display-test` 启动后只初始化屏幕：依次显示红、绿、蓝、白，
每种颜色约 350 ms，最后保持白屏。串口应报告显示测试完成，且不会启动
Wi-Fi、音频或按钮。

ST7735S 使用只写 SPI，固件无法从总线上确认屏幕是否真的存在。因此“串口
无报错”不等于屏幕通过，必须实际观察四种颜色。若黑屏、颜色顺序异常、图像
偏移或开发板复位，立即拔掉 USB，记录现象并拍照，不要带电改线。
