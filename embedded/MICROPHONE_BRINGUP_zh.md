# I2S 麦克风首次接线与自检

本文用于 OLED 阶段通过后的 I2S 麦克风隔离测试。测试期间保留已经验证的
0.91 英寸 OLED，但不要连接 MAX98357A、扬声器、按钮或电池。

当前圆形麦克风模块的接口形式与 INMP441/MSM261 系列兼容，但现有照片没有
拍清芯片本体丝印，因此文档暂时使用通用名称“I2S 麦克风”，不把具体芯片
型号作为已经确认的事实。

## 专用固件

只使用 `fuji-devkit-s3-mic-test`。它会：

1. 保持 OLED 连接并显示测试状态；
2. 将 GPIO8 保持为低电平，禁止外部功放；
3. 只创建 I2S 接收通道，GPIO15 不输出扬声器数据；
4. 使用 GPIO18/GPIO17 分别提供 SCK/WS 时钟；
5. 等待板载 `BOOT` 按钮，按下并松开后才开始录音；
6. 从 GPIO16 采集左声道，依次测量安静、说话和拍手三个阶段；
7. 在 OLED 和串口显示原生峰值、RMS、填充位和上游缩放削波统计；
8. 将三段原生 PCM 保存为 16 kHz、16-bit、单声道 WAV 到专用分区；
9. 测试结束后关闭 I2S 接收并保持离线，不启动扬声器、Wi-Fi 或小智应用。

## 接线前检查

先拔掉 `COM` USB，保持电池断开。不要移动已经验证的 OLED 四根线。
在连接前拍摄 I2S 麦克风模块正反面，确认模块丝印确实包含 `VDD`、`GND`、
`SCK`、`WS`、`SD` 和 `L/R`。不同模块的物理排列可能不同，不能只按照片中
引脚所处的位置猜测。

## 断电接线表

| I2S 麦克风丝印 | ESP32-S3 | 作用 |
|---|---|---|
| `VDD` | `3V3` | 麦克风电源，禁止接 `5V`/`VIN` |
| `GND` | `GND` | 与开发板和 OLED 共地 |
| `SCK` | GPIO18 | I2S 位时钟 BCLK |
| `WS` | GPIO17 | I2S 左右声道时钟 |
| `SD` | GPIO16 | 麦克风数据输入 |
| `L/R` | `GND` | 选择固件采集的左声道 |

所有插拔都必须在 USB 断开时进行。若使用面包板电源轨分配 `3V3` 和 `GND`，
先用万用表确认所用轨道没有在中间断开，也没有与相邻电源轨相连。

## 通电前暂停点

接线完成后仍不要插 USB。逐线用通断档确认模块焊点到开发板引脚，并额外
确认 `VDD` 与 `GND` 之间没有持续蜂鸣或接近 0 欧姆的短路。拍摄一张能同时
看清 INMP441 丝印和开发板 GPIO16/17/18 端点的俯视照片，检查后再通电刷机。

## 测试现象

刷入固件并打开串口后，OLED 显示 `MIC RECORD / press BOOT to start`。
短按并松开板载 `BOOT` 后，OLED 显示 `MIC READY` 并倒计时约 3 秒，然后
严格跟随 OLED 提示完成一次约 11 秒的受控测试：

1. `MIC QUIET`（3 秒）：保持安静，不说话，也不要碰面包板；
2. `MIC SPEAK`（5 秒）：在约 30--50 cm 处用正常音量连续说话；
3. `MIC CLAP`（3 秒）：在一臂距离轻拍两三次手，不要敲模块或桌面。

固件以 `native_*` 报告 24 位 I2S 数据等效转换为 16 位后的原生指标；
`xiaozhi_clipped` 只模拟小智上游 `>>12` 缩放可能产生的削波，不等同于
麦克风芯片本身已经削波。三个阶段的原生 RMS 应随声音明显上升。
完成后 OLED 保持 `WAV READY`，此时可使用 `esptool read-flash` 从日志给出的
`flash_offset` 读取 WAV。读取 Flash 会让芯片暂时进入下载模式，但不会擦除
录音；读回结束后会自动复位。

正常接线应持续产生 I2S 样本，安静和说话时的 `native_peak`/`native_rms` 数值应有明显
变化，最后显示 `MIC DONE`。以下情况需要立即记录完整串口日志并停止：

- `no I2S samples`：时钟、数据或供电可能未连接；
- `MIC SILENT`：可能接错 `SD`/`L/R`，或选中了固件未采集的右声道；
- 三个阶段数值接近、`response_ratio` 小于 `1.5`：先严格按屏幕提示重测；
- `padding_nonzero` 长期明显高于 0：可能是数据格式或时序不匹配；
- 开发板反复复位、模块发热或出现异味：立即拔掉 USB，不要带电改线。
